#+title: Symac package map
#+startup: overview

* Rule

Editor and LLM-workstation primitives belong in the Symac platform.
Everything domain-specific belongs in separately loadable ASDF systems.

* Platform

| System | Responsibility |
|--------+----------------|
| symac/core | lifecycle, conditions, events, capability/effect primitives |
| symac/editor | Lem integration and editor protocol |
| symac/lisp | Common Lisp live-development primitives |
| symac/model | model identity/capabilities |
| symac/provider | provider protocol |
| symac/message | typed messages/content parts |
| symac/session | persistent conversations |
| symac/context | context references, packing, selection |
| symac/prompt | prompt representation/rendering |
| symac/tool | typed tools and effects |
| symac/agent | agent runtime |
| symac/chain | composable pipelines |
| symac/graph | resumable state graphs |
| symac/language | declarative AI/workflow language |
| symac/package | extension/package contribution protocol |
| symac/workstation | integration facade |

No package above may be required merely to open Symac.

* Distribution

=symac-distribution= selects and configures a coherent default set.

It may provide strong defaults.  Those defaults are not part of the low-level
library contracts.

The distribution is allowed to feel opinionated and integrated.  The packages
must remain reusable independently.

* StarIntel family

- =symac-starintel-targets=
- =symac-starintel-datasets=
- =symac-starintel-graph=

LLM, graph, or package APIs.
